    About This Engine

    This tool runs the Real-ESRGAN x4 super-resolution model fully inside your browser using ONNX Runtime Web, with WebGPU acceleration and WASM fallback. Video files are processed frame-by-frame using FFmpeg.wasm, enhanced with AI, then re-encoded into MP4.
